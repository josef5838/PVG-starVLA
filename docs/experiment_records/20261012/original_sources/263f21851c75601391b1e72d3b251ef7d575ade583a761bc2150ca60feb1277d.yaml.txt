# ── VGGTOmegaOFT, two-level hierarchical gated memory, stack_blocks_three ───
# HierarchicalGatedMemoryPool: 3 chunks of 8 consecutive timesteps each
# (pool_num_chunks=3, pool_chunk_timesteps=8, via
# robotwin_stack_blocks_three_hist24stride1's 24-consecutive-timestep
# window). Each chunk gets its own separate VGGT-Omega backbone pass (real
# cross-frame attention within the chunk, none across chunks), then a
# GatedMemoryPool-style flat pool compresses it to a 64-token chunk summary;
# the 3 summaries fold into a persistent global memory via
# GatedRecurrentMemoryPool's bounded gated update. Unlike every other
# pool_type tried so far, this is NOT capped at a fixed 16-real-step
# lookback — offline-validated stable (memory norm exactly bounded, 1.000x
# range) over 25 chunks (~200 frames), vs. 24.5x unbounded growth for naive
# residual accumulation on the same chunk summaries. Paired with
# ablation_vggt_omega_state_suppressed_stack_blocks_three_gated_self_attn.yaml
# (flat baseline, same task) for later comparison — see memory_pool.py.
#
# per_device_batch_size reduced further than hist8stride1's batch=32 (which
# needed that reduction for a single 24-image chunk): 3 sequential backbone
# passes per sample retain gradients simultaneously for backprop through the
# full chunk sequence, so total activation memory is higher than any single
# pass alone even though peak per-call attention memory matches hist8stride1.
# ─────────────────────────────────────────────────────────────────────────────
